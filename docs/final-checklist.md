# PillMind - Final Sunum Öncesi Kontrol Listesi ✅

Jüri karşısına çıkmadan önceki **son 1 saatte** adım adım yapılacak fiziksel ve teknik kontroller dizisi. Kriz durumlarında hayat kurtarır.

## 💻 Teknik / Ortam Kontrolü
- [ ] Uygulama çalışır durumda mı? (`npm run dev` veya build çıktısı)
- [ ] Tarayıcı `localhost:3000` ekranında açık mı?
- [ ] Farkında olmadan hata mesajı basılmış sekme var mı? Sayfayı F5 ile yenileyip temizleyin.
- [ ] Varsa ekstra arka plan uygulamalarını (Spotify, Discord, VSCode eklentilerinin bildirimleri) kapatın. "Do Not Disturb" (Rahatsız Etmeyin) modu açık olsun.
- [ ] Sunum yapılacak ekranda Tarayıcı oranı (Zoom) %100 veya %110 mu? Çok küçük görünmesinden kaçının.

## 🛜 Ağ ve API Kontrolü
- [ ] Hackathon salonunun Wi-Fi ağı bağlı mı? 
- [ ] Demo yapmadan önce **sadece 1 kez** Gemini'nin cevap verip vermediğini test edin. (Sarı bir etkileşim örneği deneyin).
- [ ] İnternet koparsa `docs/fallback-demo.md` devreye nasıl girecek? Yedek statik ekran görüntüleri masaüstünüzde hazır klasörde açık mı?
- [ ] (Eğer hotspot kullanılacaksa) Telefonunuzun bataryası dolu ve internet paylaşıma açık mı?
